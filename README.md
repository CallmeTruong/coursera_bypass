# Coursera Locking Browser - Unlocked Mod

This is a modified version of the Coursera Locking Browser (v0.6.6) that removes all restrictive features such as kiosk mode, full-screen enforcement, shortcut blocking, and background application detection. It allows you to take assessments in a standard, unrestricted window environment.

---

## 🚀 Quick Installation Guide

This guide is for users who already have the modified `app.asar` file. No programming or technical knowledge is required.

1. **Install the original application:** Download and install the official **Coursera Secure Assessment Browser v0.6.6** on your computer. 
2. **Close the application:** Make sure the application is completely closed and not running in the background.
3. **Open the installation folder:** Open **File Explorer**, copy the exact path below, paste it into the address bar, and press Enter:
   `%LOCALAPPDATA%\coursera_locking_browser\app-0.6.6\resources`
4. **Replace the file:** Copy the modified `app.asar` file you received and paste it into this folder. Choose to **Replace/Overwrite** the existing file when prompted.
5. **Done!** You can now go back to the Coursera website and launch your assessment as usual. The application will open in its unlocked state.
